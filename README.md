# WORD QUEST ⚔️📖
> **“How well do you know the Word?”**

A premium, production-ready Bible web gaming platform designed for Christian youth groups, families, Bible scholars, and anyone seeking an engaging way to test and deepen their Scripture knowledge.

---

## 🌟 Key Features

### 🎮 8 Distinct Game Modes
1. **Bible Blitz** — Fast-paced timed multiple-choice questions with dynamic combo multipliers (1.0x – 3.0x), countdown tension, and instant Scripture citations.
2. **Who Am I?** — Progressive 4-clue mystery detective trial where earlier guesses award higher bonus multipliers.
3. **Bible or Not?** — High-stakes fact-check arena testing whether statements are authentic Scripture or cultural misconceptions.
4. **Complete the Verse** — Fill-in-the-blank Scripture memory challenge displaying the full revealed verse and reference.
5. **Who Said It?** — Speech bubble quote attribution testing character dialogue across Old & New Testaments.
6. **Bible Timeline** — Interactive chronological ordering of monumental redemptive history events.
7. **Bible Sort** — Multi-bucket category sorting of characters, covenants, and books.
8. **Daily Bible Challenge** — Daily rotating 10-question quest with streak bonuses and coin bounties.

### 🗺️ 10-Level Historical Journey
* **Level 1: The Beginning** (Genesis)
* **Level 2: The Journey** (Exodus & Wilderness)
* **Level 3: Kings & Kingdoms** (Historical Books)
* **Level 4: Voices of the Prophets** (Major & Minor Prophets)
* **Level 5: Wisdom & Praise** (Psalms, Proverbs, Ecclesiastes, Job)
* **Level 6: The Life of Jesus** (The Four Gospels)
* **Level 7: The Early Church** (Acts of the Apostles)
* **Level 8: Letters of Faith** (Romans to Jude)
* **Level 9: The Revelation** (Apocalypse & Triumph)
* **Level 10: WORD MASTER** (Ultimate 66-Book Apex Challenge)

### 🔊 Procedural Web Audio API Sound Engine
* Dynamic harmonic chimes rising with streak combo level
* Tactile button clicks, wrong-answer thuds, level complete fanfares, and ambient background music synthesized in pure Web Audio.

### 🪙 Economy & Progression
* **Wisdom Coins** earned through accurate play and daily streaks.
* **Sanctuary Shop**: Spend coins on 50/50 strikes, time freeze (+15s), clue scrolls, and life refills.
* **16+ Achievements**: Multi-tier badges (Bronze, Silver, Gold, Diamond).
* **Leaderboards & Social Challenges**: Shareable challenge links to invite friends.

### 🛡️ Dedicated Admin Portal (`/admin`)
* Full question database editor with validation.
* Batch CSV question importer.
* Live player and question accuracy analytics.

## 🚀 Getting Started

### Prerequisites
* Node.js 18+
* npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/amazinernest/bible-quest.git

# Navigate to project directory
cd bible-quest

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm start
```
